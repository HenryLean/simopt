# simopt-tools

A personal toolkit project containing a collection of useful scripts and utilities for the usage of the other projects that focus on simulation and optimization.

## Features

- Various practical scripts
- Easy to extend and maintain
- Suitable for individual or team use

## Usage

1. Clone the repository:
    ```bash
    git clone https://github.com/HenryLean/mytools.git
    ```
2. Enter the directory and install the package in the visual environment as needed:
    ```bash
    pip install .
    ```
